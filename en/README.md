# AI英単語 LP

静的HTML/CSSのLPです。依存インストールなしで確認できます。

```sh
open site/index.html
```

## 構成

- `index.html`: LP本体
- `styles.css`: LPスタイル
- `demo.js`: SwiftのLevel 1プレビュー単語と学習ロジックをもとにしたLP内体験デモ
- `assets/`: LPで使う画像
- `assets/demo-words/`: LP内体験デモ用にアプリ本体の画像・音声をコピーした素材
- `presentation.md`: 訴求整理、競合優位性、コピー候補

## 差し替え予定

- 正式アプリ名
- App Store URL
- スクリーンショット
- リリース時点の収録語数
- サポート/プライバシーポリシーへのリンク
